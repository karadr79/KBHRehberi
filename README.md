# KBH Rehberi

KDIGO kılavuzlarına (2013 Lipid, 2017 KBH-MKB, 2020 Nakil Adayı, 2021 Kan Basıncı, 2022 Diyabet, 2024 KBH, 2025 ADPKD, 2026 Anemi ve 2027 odaklı güncelleme taslağı) dayalı erişkin kronik böbrek hastalığı yönetim rehberi.

- 16 konu modülü, kanıt düzeyli öneriler (1A–2D, UN, NG)
- 23 klinik hesaplayıcı (eGFR, KFRE, Mayo sınıfı, demir/ESA, finerenon, PTH hedefi, girişim öncesi ilaç planı vb.)
- Çevrimdışı çalışan PWA: ana ekrana eklenebilir

Uygulama: https://karadr79.github.io/KBHRehberi/

Klinik karar desteği amaçlıdır; hasta özelinde klinik değerlendirmenin yerini tutmaz.
